# MiniCut

本地优先的 AI 视频精选与粗剪工作台。将讲座、教程、访谈、播客和口播视频转成可审阅的精选片段，再导出视频和字幕。

**工作流程：导入 → 转录 → 精选片段／口播清理 → 人工精修 → 导出。**

视频处理在本地完成；启用 DeepSeek 选材时，转录文本会发送至配置的模型服务。模型选择原文片段 ID，由程序解析时间码并验证剪辑，不让模型直接编造媒体时间。

## 功能

| 能力 | 说明 |
| --- | --- |
| 项目与素材 | 命名项目、切换项目、本地视频上传、素材列表与源视频预览 |
| 极简模式 | 保存常用工作流，选择视频后一键转录、生成；可自动导出，随时切回完整模式 |
| 语音转录 | MLX / Whisper 后端，中文与英文选择，词级时间戳；长素材分块处理、保存进度并复用缓存 |
| AI 选材 | 播客精选（问答对话）、知识精华（个人陈述）；自定义要求、数量、时长和内容重复上限 |
| 开场预告 | AI 选择或手动复制原话作为开场预告，再播放完整的所选正片；保留正片中的原句 |
| 开场预告转场 | 渐隐渐入，或独立插入电视花屏＋哔声；可选关闭、0.15、0.3、0.5、1 秒，随版本保存 |
| 人工精修 | 字幕文字修改、手动调整源起止时间、源时间跳转、片段删除与恢复、顺序调整、历史版本查看 |
| 视频导出 | 单条或批量 MP4、独立 SRT、软字幕或烧录字幕；720/1080 档、横竖屏及方形画幅 |
| 任务管理 | 进度、取消、恢复、逐条重试；模型响应复用、Token 用量和可配置费用估算 |
| 开发接口 | CLI、本地 HTTP API 与交互式 API 文档 |

开场预告目标默认 5 秒，可自定义 1–60 秒，优先保持原话与必要背景完整。“完整正片”指作品选中的完整论述，不是整个原始长视频。渐出和渐入分别使用所选时长，极短片段会自动缩短渐变，不改变总时长。电视花屏＋哔声为独立片段：开场预告 → 花屏与哔声 → 正文，不覆盖讲话；总时长增加所选转场时长，正文字幕同步顺延。素材来源见 [SOURCES.txt](src/minicut/assets/SOURCES.txt)。

## 环境要求

- Python 3.11 或更高版本、uv；Windows/Linux CPU 转录本轮以 Python 3.11 为兼容目标。
- Node.js 22.12 或更高版本、npm。
- FFmpeg 与 ffprobe，均需可从终端调用；需要 `libx264` 编码器，烧录字幕还需要 `subtitles`/libass 滤镜和中文字体。
- Apple Silicon 可使用 MLX；其他平台可使用 PyTorch Whisper。转录后端和模型需另行安装。
- AI 选材需要可用的 DeepSeek API 密钥；仅转录、编辑和渲染无需该密钥。

## 安装与启动

以下命令从仓库根目录执行。初次安装：

```bash
uv sync --python 3.11
# Apple Silicon：
uv pip install mlx-whisper
# 使用 PyTorch Whisper 时改为：uv pip install openai-whisper
cd web
npm ci
cd ..
```

复制 `.env.example` 为 `.env`，填写 `DEEPSEEK_API_KEY`。已有配置时直接编辑，避免覆盖密钥。可通过 `DEEPSEEK_MODEL`、`DEEPSEEK_BASE_URL` 调整模型与服务地址。

macOS / Linux（Bash、Zsh）启动后端：

```bash
MINICUT_PROJECTS_ROOT="$PWD/projects" \
uv run --no-sync --env-file .env minicut-api
```

Windows PowerShell 启动后端：

```powershell
$env:MINICUT_PROJECTS_ROOT = Join-Path $PWD.Path "projects"
uv run --no-sync --env-file .env minicut-api
```

另开终端，从仓库根目录启动前端：

```bash
cd web
npm run dev -- --host 127.0.0.1
```

打开 [Web 工作台](http://127.0.0.1:5173)。[API 文档](http://127.0.0.1:8000/docs)列出全部接口。

- 首次转录可能下载模型；已有对应 Hugging Face 模型缓存时，可在后端启动命令前加 `HF_HUB_OFFLINE=1`。不同项目通常共享同一模型缓存，无需在每个项目复制模型。
- `--no-sync` 保留单独安装的可选转录依赖。更新基础依赖时使用 `uv sync --inexact`。
- 更换后端端口时设置 `MINICUT_API_PORT`，同时给前端设置对应的 `MINICUT_API_URL`，例如 `http://127.0.0.1:8001`。
- 单条导出、批量导出和成片预览共用独立 FFmpeg worker，默认同时运行 2 个任务；可通过 `MINICUT_EXPORT_CONCURRENCY` 调整为 1–4。并发越高，CPU、内存和磁盘占用越大。
- 转录／AI 计算、FFmpeg 和工作流协调使用独立后台队列，每个队列最多等待 64 个任务；排队不占用 HTTP 共享线程池。队列满时新请求返回 503，已创建但未接收的任务会标记为可恢复的失败状态；排队任务可立即取消，查询和取消接口仍可使用。
- 保持两个终端运行；同一个项目目录只启动一个 API 进程。默认服务面向本地使用，没有面向公网的账户与权限系统。
- 同一 API 进程内可并发上传素材；项目清单的读取、去重与写回按项目串行执行。不要同时通过 CLI 或其他进程写入同一项目目录，进程内锁不协调跨进程写入。

## Windows 与 Linux 安装补充

本轮兼容目标为 Windows 11 x64、Ubuntu 22.04/24.04 x64，使用 Python 3.11 和 CPU PyTorch Whisper；GPU 加速及其他发行版不在本轮验收范围。自动化配置使用 Windows Server 2022 和 Ubuntu runner，不能替代 Windows 11 的人工验收。macOS Apple Silicon 继续使用 MLX。具体验证状态见下方「跨平台验证」。

先安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)、[Node.js](https://nodejs.org/en/download) 22.12+ 和 [FFmpeg](https://ffmpeg.org/download.html)。安装后重新打开终端，确保 `uv`、`node`、`npm`、`ffmpeg`、`ffprobe` 可调用。Windows 使用包含 libass 的 FFmpeg 构建；Ubuntu 可安装系统媒体工具与字体：

```bash
sudo apt-get update
sudo apt-get install ffmpeg fonts-noto-cjk
```

从仓库根目录安装基础依赖和 CPU 转录后端。以下命令在 PowerShell、Bash 中均可使用：

```text
uv sync --python 3.11
uv pip install torch --index-url https://download.pytorch.org/whl/cpu
uv pip install openai-whisper
cd web
npm ci
cd ..
```

CPU PyTorch 安装方式参考 [PyTorch 官方安装页](https://docs.pytorch.org/get-started/locally/)，Whisper 依赖参考 [Whisper 官方说明](https://github.com/openai/whisper#setup)。基础依赖不包含转录引擎；重新同步时使用 `uv sync --inexact` 保留单独安装的后端。

PowerShell 初次复制配置（已有 `.env` 时保留）：

```powershell
if (!(Test-Path .env)) { Copy-Item .env.example .env }
```

Bash 初次复制配置（已有 `.env` 时保留）：

```bash
if [ ! -f .env ]; then cp .env.example .env; fi
```

填写 `.env` 后，按上方对应系统的命令启动两个服务。若 PowerShell 的脚本执行策略阻止 `npm`，可使用 `npm.cmd ci` 和 `npm.cmd run dev -- --host 127.0.0.1`。

新转录与新工作流从后端读取默认值：Apple Silicon macOS 为 MLX / large-v3-turbo；Windows、Linux、Intel macOS 为 PyTorch Whisper / small。CPU 转录速度取决于硬件，人工验收可先选 tiny。首次运行下载模型；Whisper 使用自己的模型缓存，`HF_HUB_OFFLINE` 只适用于相关 Hugging Face/MLX 缓存。已有任务和工作流保留原引擎与模型，迁移使用时请明确选择当前机器支持的引擎，不会自动改写历史任务。

Windows 默认检测微软雅黑，Ubuntu 默认检测 Noto Sans CJK。找不到字体时安装本机中文字体，或在 `.env` 中同时设置 `MINICUT_SUBTITLE_FONT_PATH` 和 `MINICUT_SUBTITLE_FONT_NAME`；字体路径不做 URL 编码。Windows 建议使用较短的项目目录，长路径是否可用还受系统配置和 FFmpeg 构建影响。项目记录包含本机媒体路径与字体选择，复制项目目录到另一台机器不等于完成数据迁移。

### 跨平台验证

`.github/workflows/platform-tests.yml` 提供 Windows Server 2022、Ubuntu 22.04/24.04 的针对性后端及真实 FFmpeg 测试，并运行前端测试与构建。它覆盖后端默认值、进程存活检测、任务恢复、媒体导入、Unicode/空格/百分号路径、软字幕/烧录字幕、原音保留、封面与长滤镜文件读取；转录后端单元测试使用替身，不下载模型或调用付费 AI。推送后可在仓库的 Actions → Platform compatibility 查看各平台结果；请以对应提交的运行结果为准，本地 macOS 测试不能证明目标系统已经通过。

人工验收请在每个目标系统执行：

1. 按安装说明启动服务，建立项目，导入文件名包含中文、空格和 `%20` 的讲话视频。
2. 确认新转录和新工作流默认使用 PyTorch Whisper，先以 tiny 模型完成一次真实转录，检查词时间与源语言。
3. 生成或载入候选，修改范围并保存，分别播放快速预览和成片预览；AI 生成会使用已配置的模型服务并产生相应费用。
4. 分别导出软字幕与烧录字幕 MP4、SRT 和封面，检查中文字幕、原音、首帧及下载文件；试听片头、切点和片尾。
5. 运行口播清理并检查长素材/较多切点；取消任务后恢复，并在后端重启后确认旧任务可恢复、已有作品可读取。
6. 在 macOS 检查原 MLX 默认值和既有项目的编辑、预览、导出。

## 操作说明

### 极简模式与我的工作流

新建项目时可选择「极简模式」或「完整模式」；项目顶部始终提供模式切换。旧项目默认保持完整模式，切换使用同一份素材、作品和历史记录，正在执行的工作流继续运行。模式选择在当前浏览器中记忆。

点击「管理我的工作流」打开弹窗，填写名称，组合已有生成预设、导出预设和可选封面模板，设置转录引擎、模型及源语言后「另存为工作流」。完整模式也提供这个入口：先在原界面保存配置，再点击「载入当前素材已保存配置」，会载入生成草稿、转录配置，以及该素材最近生成集合的第一条作品的画面、字幕排版和开场转场设置。封面通过已保存模板复用；未保存的修改和逐条作品内容不进入工作流。可另存、更新、重命名或删除工作流。

工作流库保存在项目根目录的 `.minicut/workflows.sqlite3`，跨项目共享。工作流保存实际配置及封面模板背景的副本；修改或删除原预设、模板不会改变已有工作流。更新工作流不会改变已提交任务，失败恢复仍使用提交时的配置。

极简模式将视频、工作流和生成按钮集中在顶部，下方并排显示候选作品与试听预览；常规桌面窗口内无需滚动整个页面，较多候选在列表内滚动。工作流管理和生成详情使用弹窗，完整模式的管理入口位于添加素材一行。选择本地视频或项目已有素材，选择工作流后点击「一键生成」。新视频自动导入，再依次转录、AI 选材、可选翻译和应用成片配置。默认完成后展示结果：可以试听、勾选作品并「导出已选作品」，或点击「精修」进入完整模式。工作流的「完成方式」也可设为「自动导出全部结果」，此时主按钮变为「一键生成并导出」，完成后可查看包含视频、字幕、封面、标题及文案的导出结果页。该操作只生成本地文件，不发布到外部平台。

一次运行处理一个长视频；日常沿用上次选择的工作流。视频在本地处理，转录文本会发送至配置的 AI 服务并可能产生模型费用。任务在后端执行，刷新、关闭页面或切换模式不会中断后端流程；停止后端会中断任务，可重新进入项目并「继续工作流」。取消会保留已完成阶段，继续时复用成功的转录、选材和导出任务；导出失败不会重新调用 AI。任务记录保存在项目的 `.minicut/jobs`。

### 1. 导入与转录

每次新转录保留独立的完整词级版本。作品集合在生成开始时绑定该版本，显示、编辑、历史、预览和导出持续使用同一份词级数据；更换模型或语言重新转录只影响后续新建集合。恢复生成任务也沿用其已绑定转录。旧集合会在首次读取或下次转录覆盖前绑定当时仍可用的转录；升级前已经被覆盖的数据无法恢复。绑定版本缺失或损坏时会明确报错，不自动使用最新转录。

1. 在「我的项目」创建并命名项目，进入后展开「导入素材」。
2. 选择本地视频并等待上传完成；上传会在项目目录保存一份副本。
3. 在「当前素材」选择视频，转录引擎、模型、语言和开始按钮直接显示。
4. 选择已安装的后端、模型和视频实际语言，开始转录。中文视频选择中文。
5. 进度条显示已完成的转录块；尚无分块进度时显示处理中。长素材逐块保存进度，失败后可恢复已保存块。

### 2. 生成精选

1. 进入「生成」，选择预设；「剪辑提示词」统一填写选材方向、受众、主题和需要保留的背景，可直接修改或恢复默认。
2. 在「高级参数」设置数量、最短与最长秒数、不同作品间素材重叠上限；需要开场预告时勾选「原话开场预告」并设置目标秒数。时长目标包含开场预告；为了完整句可超出最多 `min(最长秒数 × 20%, 15 秒)`，短但完整的内容也可保留。默认「连续正文」保留起止点间全部内容，只有主动选择「精简拼接」才允许跳切。
3. 重叠上限只约束多条候选共享的原素材：两条各 60 秒、30% 上限时最多共享 18 秒；生成一条时无需设置。开场预告在同条正片中重复不受此设置限制。
4. 点击「生成候选」。选材后对连续正文进行一次词级句界复核，模型只能引用提供的词 ID；边界调整限定在前后 10 秒内，不确定时提示人工检查。这些步骤可能产生模型服务费用。
5. 可勾选「翻译字幕」，选择中文／英文及双语／仅译文。候选确定后才调用 DeepSeek 翻译候选字幕，产生额外模型费用；重复字幕复用译文，不改变原音和剪辑时间。
6. 查看候选标题、选材理由、时长和不足说明。内容不足时可能返回较少候选。

生成表单自动保存到本地项目：每个素材分别保留选中的预设、各预设的剪辑提示词草稿及全部生成参数。关闭开场预告或翻译后，其待用参数仍保留；刷新、重新打开项目或生成结束不会清空。新素材沿用项目最近保存的配置；已有素材优先恢复自己的草稿，尚无草稿时从自己的最近一次生成恢复。保存状态显示在表单上方；保存失败可重试，尚未同步的修改暂存在当前浏览器中，重新打开后继续保存。

展开「生成历史」可查看当前素材或整个项目历次提交的提示词、参数和任务状态，包括失败及取消的任务。「载入为草稿」只填写并保存新草稿，不自动生成，也不更改已有作品或历史记录。旧记录没有保存的字段显示「未记录」，不以当前默认值冒充历史；载入时会提示使用默认设置补齐。新任务在提交时保存实际解析后的配置快照，恢复生成继续使用该快照。高级参数可关闭「限制目标时长」以保留不限时配置。

「预设」下拉框同时提供内置预设和「我的预设」。在「管理我的预设」填写名称并点击「另存为预设」，会保存当前剪辑提示词及全部生成参数，供不同项目和素材复用。预设库保存在当前项目根目录下的 `.minicut/generation-presets.sqlite3`，与单个项目独立；关闭应用或删除某个项目不会清空预设库，同一项目根目录下的所有项目共用它。

「AI 生成」下方第一项是「预设」。选择「我的预设」后出现「应用内容」的两个按钮：点击「仅提示词」直接替换剪辑提示词，保留当前基础选材方式及高级参数；点击「全部参数」直接填写完整工作流程。仅选择自定义预设不会改变当前草稿或触发生成。应用后继续编辑只自动保存项目草稿；点击「用当前配置更新预设」才更新全局模板。可单独重命名、删除或另存为新预设；同名预设会提示换名。更新或删除模板不会改变已应用的草稿、历史配置或已有作品，生成历史保留当次使用的预设名称和实际文字。切回内置预设可恢复它自己的提示词草稿。

新生成任务只提交一个剪辑提示词字段，选材方向和本次要求作为同一等级的用户内容发送，不再分配“预设 / 具体要求”的优先级；系统规则仅保留来源、输出格式和剪辑结构等约束。旧草稿和旧自定义预设的两段文字按原文顺序合并，中间空一行；旧草稿原先共用的剪辑要求会保留到各内置预设的提示词草稿中，保存后不重复追加。恢复默认会替换整个剪辑提示词。历史记录不改写：旧记录提供原始两个字段供核对，载入为新草稿时合并；恢复旧失败任务仍使用当时的提示词版本和配置，保留已成功请求的复用能力。合并提示词不会减少选材阶段，也不保证总费用下降，实际用量仍以请求记录为准。

预设与剪辑结构独立：正文模式、开场预告开关优先于提示词。精选只提供播客精选和知识精华；需要突出重点时可启用开场钩子。旧观点先行作品和任务仍可读取／恢复，载入为新草稿时转为知识精华并保留提示词。

新提交的连续精选任务使用精简句界复核格式：上下文保留连续原文，只有允许调整的开头／结尾附词编号；正文起止时间由本地校验，不发送逐词绝对时间。启用钩子时额外提供相对词时间，供模型判断钩子时长。超过两分钟的候选沿用开头、结尾及已有钩子附近的有界上下文，明确标记中间省略的区间。旧任务恢复仍沿用旧格式，复用已有成功请求；需要使用新格式时请重新提交任务。

示例要求：

> 面向没有背景知识的观众，选出两个不同主题，每条 60 至 120 秒。先放约五秒吸引注意的完整原话预告，再接完整论述。保留否定、限定条件和必要背景，不生成旁白。

### 口播清理

在「AI 生成 → 处理方式」选择「口播清理」，完成词级转录后点击「一键清理」。这是独立流程：默认保留整段素材，只删除明确口误（后文已有正确重说）、失败起句、机械重复和无意义填充词。模型只接收短词编号与原文，返回删除编号范围与类别，由本地映射回原词 ID 和时间，不选材、不生成钩子、标题、选材理由或发布文案；长素材按词分块并携带邻近上下文。正常短素材一次清理请求，可选翻译另行调用模型。

长停顿由本地 FFmpeg 扫描源音频：超过 1 秒的静音压缩至约 0.3 秒，保留边界余量与转录词。自然换气、强调、否定和限定应保留；转录不可靠或词级边界重叠的建议保留并提示复核。转录遗漏的结巴或语气词可能无法识别，剪辑质量需人工试听。没有可删除内容时保留完整素材。

结果只生成一条「素材名 · 清理版」，可在编辑区修改作品名。清理审阅显示前后时长、删除类别与源时间，可试听原片上下文、清理后的切点，以及逐处恢复；恢复保存新版本，不重新调用模型。后续字幕、可选翻译、封面和导出沿用现有功能。发布文案留空并显示「此流程不生成文案」，封面文字仍可手动编辑。生成和编辑不渲染视频，显式预览／导出才执行渲染。

清理详情将本地校验提示折叠为保留原因，不确定的建议仍保留原文。删除清单每页 20 处；点击试听会直接播放，播放器显示在清单前，可反复对比原片和清理后切点。

按源时间顺序的整段清理使用单路视频筛选和逐段音频样本拼接，避免把大量切点展开为同时读取长素材的渲染分支。视频统一输出时钟，音频按样本拼接，避免切点数量增加时累计偏移。临时音频会占用磁盘空间，渲染完成或失败后清除；长视频仍需编码完整成片，快速试听无需等待渲染。

极简模式的工作流也可选择口播清理并复用字幕、画面和封面配置。已有作品不自动改写；恢复任务沿用保存的流程与请求格式（早期清理任务可能仍是精选流程，独立清理 v1 仍使用原词 ID）。新提交清理任务使用 v2 短编号格式，不重复发送整份可删除词 ID 列表，原始时间戳始终保留在本地。

### 3. 预览、编辑与开场预告

1. 选择候选，直接使用「快速预览」播放源素材，不等待渲染。可播放全部片段，或在卡片中试听开头、结尾和整个片段。跨片段跳转可能短暂停顿。
2. 编辑区默认以紧凑字幕预览列出片段，点击展开起止时间、字幕及分句操作，再点一次收起。收起保留输入，未保存修改会显示提示。新生成作品按转录句子分成编辑片段；连续正文保留片段之间全部停顿，分句不产生跳切。在「编辑」逐句修改字幕并保存。已有长片段可点击「按句拆分片段」，创建新版本并重置被拆分片段的字幕校正；原版本保留。较长的校正字幕也会分页显示，不整段铺满画面。文字修改仅影响字幕，不改变声音。
如果自动分句仍把多轮对话放在一起，可在该片段的字幕框中每句换一行，点击「预览分句时间」，核对后「确认分句」。只添加换行和标点，程序按原转录词级时间戳匹配；已改过文字可先点「使用转录原文」。不匹配或换行落在一个转录词内部时会提示调整，不猜时间；分句后再分别校正字幕。此操作本地完成，无模型费用，保留原片段全部音视频和停顿，只保存一个新版本。

在翻译过的片段中，可编辑「译文」并点击「保存译文与显示方式」，双语／仅译文随作品版本保存。快速预览仍播放原素材；生成成片预览及导出 MP4／SRT 才显示所选字幕。修改原文后需同步核对译文；更改范围或拆分句子会清除受影响的旧译文，此时暂显示原文，可手动补充译文。

3. 删除不需要的片段，误删可以恢复。至少保留一段正文。
4. 每张片段卡片集中提供字幕、起止时间、排序及开场预告操作；点击「复制为开场预告」。系统复制原话到开头，正片保留原片段；「取消开场预告」去掉该开场副本。
5. 在「开场转场设置」选择效果与时长。设置自动保存为新版本，显式生成的成片预览和后续导出使用该版本；旧导出文件不会被覆盖。
6. 使用起止时间输入或开始／结束各自的加减按钮调整范围。步长可选 0.1、0.5、1 秒。修改立即用于快速试听，不启动渲染。
7. 范围修改先进入草稿，可撤销、重做或放弃；「保存修改」一次保存多个片段并产生一个新版本。保存会重新提取变更范围的字幕，并重置这些片段已校正的字幕，因此请先调范围、再校正文案。保存失败保留草稿；切换作品提示保存或放弃。
8. 手动范围不能超出素材；相邻片段若重叠会重复播放。开场预告和正文范围独立，缩短开场预告不剪掉正文。历史版本只读，旧作品不会自动套用新选段规则。
9. 编辑区先进入「画面设置」，选择画幅、分辨率、适配／裁剪及音频处理，编辑区上方的导出预设同时包含画面和字幕设置。在「字幕设置」选择软字幕／烧录字幕，并调整字号、位置及双语显示。作品设置自动记忆，供作品预览、单个导出和默认批量导出共用。预览上方只显示配置摘要，点击「调整设置」回到编辑入口。
10. 点击「生成成片预览」才按目标尺寸渲染画幅、字幕、渐变及独立花屏哔声；快速预览仍播放源素材。烧录字幕的字号、位置、换行和音视频处理与导出一致。双语烧录字幕各预留两行，第一行位置固定，第二行向下展开，不随另一种语言的行数变化而上下跳动。横竖屏按实际画幅、字号和安全宽度换行；能容纳的短译文优先保留完整，长句优先结合原文词级时间、停顿和句界分页。译文没有逐词对齐信息，无法可靠对应的分页、过短字幕页或超出建议两行的内容会在成片预览及导出结果中提示人工复核；不会自动删字或缩小字号。软字幕提供浏览器可开关的字幕轨，排版取决于播放器。目标尺寸预览需要等待渲染，不能通过快速预览判断最终字幕排版。「快速预览／成片预览」可切换查看；切换导出模式不改变当前预览。
11. 修改输出设置或保存字幕后，保留旧成片并提示预览已过期；点击「更新成片预览」才生成新效果。保存范围后仍先使用快速预览。仅作品版本和全部输出参数相同时复用已有成片；不同配置保留各自预览文件。上次预览失败或取消后，再次点击生成／更新会提交新任务；已有任务正在运行时继续复用，避免重复渲染。新任务失败后显示错误，需人工重试，不自动循环重试。未保存的范围、字幕文字或字幕设置不能直接生成成片或导出。

### 4. 导出

1. 在「导出」顶部选择「单个」，下一级选择「封面」或「画面」（默认画面）。「封面」提供封面设计和模板；「画面」核对当前作品最终配置，需要调整时点击「返回编辑调整画面／字幕」。导出按钮与任务状态始终显示在下方。
2. 批量导出时，先勾选候选，再选择顶部的「批量」。「封面」批量应用封面模板；「画面」默认沿用各作品设置，并列出每条实际配置。需要统一规格时，明确选择「统一使用批量设置／预设」，可应用预设、调整统一参数及逐条画幅覆盖，列表提示哪些作品配置不同；这些修改只作用于批次。点击某条「预览此作品的批量效果」才生成该作品的批量预览，中央明确标注配置来源，可返回作品预览。点击「导出已选作品」后，后台按并发数并行执行，其余任务排队。
3. 「编辑 → 画面设置 → 自由裁剪画面」可按百分比分别裁去上下左右边缘，参考画面亮框为保留区域。保留「原始比例」时，输出长宽跟随裁剪结果；也可继续适配固定比例。裁剪不改变时长或声音，源画面已有字幕可能被裁掉，软件烧录的字幕在裁剪后添加。批量导出也支持统一裁剪或单条覆盖。
4. 完整加边框保留整帧；居中裁切可能去掉边缘内容，不提供自动人物追踪。
5. 软字幕可在播放器中开关，烧录字幕永久进入画面。中文烧录需要中文字体；缺失时按错误提示配置字体。「编辑 → 字幕设置」可分别选择原文和译文的本机字体，填写各自字号（16–200），并调整共用的文字颜色、加粗、描边、阴影和半透明背景框。字号、描边宽度与阴影强度以画面短边 1080 像素为基准，720p 等比例缩为 2/3；原始比例按实际输出短边缩放。描边、阴影设为 0 可关闭，背景不透明度支持 0–100%。保存后生成作品新版本，需显式更新成片预览查看效果；软字幕和下载的 SRT 仍由播放器控制样式。旧作品未保存新样式前沿用原倍率排版，首次保存时界面会提示启用新样式；历史版本和旧导出文件保留原状态。
6. 任务成功后下载 MP4 或 SRT。普通切点音频淡入淡出、降噪与开场预告声画转场为独立选项。
7. 返回编辑或重新进入项目后，可在「导出」面板点击「查看导出结果页」或「查看全部导出结果」，重新打开已持久化的发布素材包。

导出设置修改后自动保存到本地项目，无需先导出。单个作品分别记住配置，编辑产生新版本后仍沿用；新作品沿用本项目最近的单个导出设置。批量按候选集合记住统一参数和逐条覆盖，新集合沿用项目最近的批量统一参数，不继承其他集合的逐条覆盖。作品设置与批量统一配置分别记忆；批量还记住当前集合明确选择的参数来源。新集合默认沿用作品设置，保留最近的批量统一配置供主动启用。旧批量配置及覆盖保留，初次使用新版时默认沿用作品设置。刷新和重启后恢复。读取中、保存中及失败提示显示在编辑区和导出按钮上方；失败时修改保留在当前浏览器，可重试保存，重新打开后继续同步。未保存的范围、字幕或封面修改仍需先保存或放弃。

「编辑 → 导出预设」支持另存、应用、更新、重命名和删除；批量启用统一设置后也可管理和应用预设。选择后点击「应用预设」才填写设置；继续编辑只保存当前配置，点击「用当前配置更新预设」才修改共享模板。预设包含画幅、分辨率、适配、四边裁剪、软字幕／烧录字幕、原文／双语／译文显示、原文和译文各自的字体与字号、颜色、加粗、描边、阴影、背景框、位置与上下顺序，以及音频淡入淡出和降噪；不包含封面设计、字幕文字、时间轴或批量逐条覆盖。存在未保存修改时，先保存或放弃再操作预设。单条应用时字幕配置保存为作品新版本；批量统一字幕配置仅作用于本批次，不修改作品版本。旧预设未包含完整字幕设置，应用时保留当前字幕排版。批量应用预设及恢复默认只改变统一设置，逐条画幅覆盖优先；「清除全部逐条覆盖」可恢复统一应用。继承配置和应用预设后请核对裁剪区域。

导出设置保存在各项目的 `.minicut/export-settings.sqlite3`；导出预设库保存在项目根目录的 `.minicut/export-presets.sqlite3`，供同一根目录下的所有项目共用。预设修改或删除不会追溯更改已应用的配置或已有导出文件。跨项目复用通过预设完成。

### 封面设计

在单条作品的「导出」面板进入「封面设计」。默认保留「直接使用成片第一帧」；切换「自定义封面」后，可选择纯色或上传 JPG、PNG、WebP 背景（最大 15 MB、3600 万像素），调整背景缩放及位置。视频画面默认来自作品第一段有效片段的起始帧，也可选择其他保留片段并调整源视频时间；不叠加软件字幕，源画面已有文字仍会保留。

封面尺寸独立于视频：9:16（1080×1920）、16:9（1920×1080）、1:1（1080×1080）、3:4（1080×1440）。切换尺寸会恢复适合该比例的默认排版。拖动画面或标题移动位置，拖动右下角调整大小；方向键微调、Shift 加速，也可通过「位置与大小」输入百分比或居中。封面标题默认填入作品标题，之后独立编辑；支持手动换行、自动换行、可用中文字体、字号、加粗、对齐、颜色与描边。预览会提示元素或文字超出边界。

点击「保存封面设计」保存独立封面版本，不增加剪辑版本或重新渲染视频。未保存的封面不能随视频导出；当前浏览器会暂存封面草稿，刷新后可恢复。保存后可单独下载 PNG 或 JPG；单条及批量视频导出使用各作品保存的封面，素材包中为 JPG。导出及恢复记录当时的封面版本，后续修改不会覆盖旧导出图片。剪辑范围修改后，若原选帧不再保留，需要重新选帧。预览和下载使用同一套本地字体及绘制规则，不调用 AI。

字体来自本机可用的中文字体；如未找到，可配置 `MINICUT_SUBTITLE_FONT_PATH` 与 `MINICUT_SUBTITLE_FONT_NAME`。上传背景、选帧缓存和封面设计历史保存在项目的 `.minicut/covers/`，与其他项目数据一同保留或删除。

封面上方的「封面模板」与生成预设使用相同的选择与管理流程：仅选择模板不会改动当前封面；点击「仅标题样式」应用字体、字号、颜色、对齐、加粗、描边和标题框，保留尺寸、背景与视频布局；点击「全部设计」应用整套尺寸和排版。两种方式都保留当前作品的封面文字和视频选帧，应用后需点击「保存封面设计」。

在「管理我的封面模板」填写名称，点击「另存为模板」，可保存当前设计供所有项目使用。编辑封面不会自动更新模板；应用模板后点击「用当前配置更新模板」才替换模板内容。支持重命名和删除，同名会提示换名。模板不保存作品标题或源视频时间，背景独立存入项目根目录的 `.minicut/cover-templates.sqlite3`；删除来源项目不会影响模板，更新或删除模板不会改变已经应用的封面及导出图片。

「批量导出 → 批量应用封面模板」可选择同一模板，点击「仅标题样式 · 保存到已选作品」或「全部设计 · 保存到已选作品」，分别保留各作品的标题和选帧，并保存各自的新封面版本，不渲染或导出视频。请先保存或放弃当前草稿；批量操作逐条显示成功或失败，失败的作品保持原封面设置。当前作品的封面面板会自动重新读取成功保存的配置。

### 5. 取消与恢复

转录进度自动更新；停止计算使用「取消转录」。转录与模型请求可能在当前块或请求结束后才响应取消。服务重启后需显式恢复，不会自动开始付费调用。已保存成功响应可以复用，尚未保存的请求可能需要重新调用。

退出前等待保存，使用 Ctrl+C 结束服务。再次使用同一个 `MINICUT_PROJECTS_ROOT` 启动即可继续。

## 存储与清理

项目数据写入 `MINICUT_PROJECTS_ROOT/<项目 ID>/`。上传素材副本、转录缓存、版本记录、预览及每次导出会累积占用空间；程序不会自动删除它们。共享转录模型缓存位于模型后端的缓存目录，不在各项目内。

在「我的项目」点击「删除项目」，确认后永久删除项目内的素材副本、转录、版本和导出，无法撤销。运行中的任务必须先取消或等待完成；项目外原视频及共享模型缓存保留。请先备份需要保留的文件。

不要仅删除 `manifest.json`，否则残留媒体仍占空间。不要在运行任务时直接删除缓存或导出目录。测试素材及运行数据不应提交到 Git。

## 限制

- 转录和选材需要人工听核，尤其是否定词、专有名词及上下文；程序不能保证开场预告的吸引力或语义完整性。
- 不提供自动人物追踪、智能构图、B-roll、配乐或旁白生成。
- 超出章节预算的不可分超长文本段可能需要拆分处理；精选模式不等同于整段清理；请使用独立口播清理流程。
- 费用估算依赖配置的价格；未配置价格或服务未返回用量时，不代表费用为零。
- MLX 需要 Apple Silicon；各平台的速度和模型可用性取决于硬件与后端。

## 开发

```bash
uv sync --inexact
uv run --no-sync python tools/check.py
cd web
npm ci
npm test
npm run build
```

后端检查覆盖测试、Ruff 和 Pyright；前端检查覆盖组件测试、TypeScript 和生产构建。FFmpeg 集成测试会实际生成并检测媒体。

```text
src/minicut/   领域模型、用例、CLI、API、转录与渲染
web/src/      React 工作台与组件测试
tests/        Python 单元与集成测试
tools/        开发检查工具
```

通过 `uv run --no-sync minicut --help` 查看 CLI 命令。提交遵循 Conventional Commits，例如 `fix: align hook controls`、`feat: configure hook transitions`、`docs: clarify setup instructions`。请勿提交密钥、模型、测试视频或生成文件。

## 剪辑数据模型与兼容性

当前 Web 精选流程使用 OutputPlan，支持多个作品、连续正文、开场预告和作品版本。EditPlan 仍用于 CLI 的旧版粗剪流程（如 plan、plan-edit、render）和「审阅现有剪辑」入口，因此保留其实现与测试；两种计划不会自动互相转换。
